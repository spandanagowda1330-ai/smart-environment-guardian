# Team Responsibility Tracker

## Project: Smart Environment Guardian

This document tracks team responsibilities and the information needed for project integration and documentation.

## Responsibilities

| Role | Responsibility | Information Needed | Status |
|---|---|---|---|
| Project Lead | Requirements, architecture, FirmGen integration, final presentation | Approved requirements and FirmGen workflow | Awaiting confirmation |
| Hardware Developer | Hardware and sensor setup | Confirmed components, pin connections, wiring details | In progress |
| Firmware Developer | Firmware development and flashing | Source file paths, build results, implementation details | In progress |
| Testing and Debugging | Testing and serial log collection | Test results, logs, issues found | Pending verification |
| Demo and Submission | Demonstration and submission evidence | Screenshots, photos, video, submission checklist | Pending |
| Documentation and Traceability | GitHub documentation and traceability matrix | Confirmed changes, implementation links, test evidence | Documentation prepared; updates ongoing |

## Documentation Follow-ups

- [ ] Confirm final requirements with the project lead.
- [ ] Obtain the confirmed hardware and wiring details.
- [ ] Record firmware file paths after code is pushed.
- [ ] Update the traceability matrix with actual implementation files.
- [ ] Add test results only after tests are performed.
- [ ] Link supporting evidence to the corresponding test IDs.
- [ ] Confirm the FirmGen workflow with the project lead.

## Update Rules

- Update this tracker when responsibilities or project status change.
- Confirm changes with the responsible teammate.
- Do not mark work complete without confirmation or evidence.
