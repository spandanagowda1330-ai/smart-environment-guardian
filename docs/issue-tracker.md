## Issue Management Guidelines

- Verify each issue with the responsible teammate.
- Update the status when new information becomes available.
- Record the resolution and supporting evidence when an issue is closed.
- Avoid marking unverified work as completed.
- Remove or revise entries that are no longer relevant.

## Status Definitions

- **Awaiting confirmation:** Information is needed from the responsible teammate.
- **Pending:** Work has not yet been completed or verified.
- **In progress:** Work has started.
- **Resolved:** The issue has been addressed and verified.
