# Evidence Collection Checklist

This checklist tracks the evidence required for the Smart Environment Guardian project.

## Build Evidence
- [ ] Firmware compilation result
- [ ] Build errors resolved, if any

## Sensor Evidence
- [ ] Temperature readings from the sensor
- [ ] Humidity readings from the sensor
- [ ] Serial monitor output with timestamps

## Alert Evidence
- [ ] Alert activates when a configured threshold is crossed
- [ ] LED and buzzer behavior verified
- [ ] Alert stops when readings return to the acceptable range

## Reliability Evidence
- [ ] Invalid or unavailable sensor readings handled
- [ ] Startup diagnostics recorded
- [ ] Error handling verified

## Final Demonstration
- [ ] Hardware setup photograph
- [ ] Video or screenshots of the demonstration
- [ ] Acceptance test results updated

## Status

All items are pending until evidence is collected and checked. Do not mark an item complete without supporting evidence.
